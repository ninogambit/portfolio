# Welcome to my Engineering Portfolio

I'm an engineer with a strong interest in Embedded Systems, Software, Electronics Design and Machine Learning. This portfolio showcases my projects combining hardware and software, from designing custom PCBs and schematics to developing embedded applications and TinyML solutions.

My work includes microcontroller programming, PCB design, Python code, signal processing, and machine learning, with a particular focus on bringing intelligent applications to resource-constrained hardware. All boards are soldered by me using a soldering iron or a hot wir gun.

I'm passionate about understanding how things work at both hardware and software levels and turning ideas into practical, working solutions.
